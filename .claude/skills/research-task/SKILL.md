# Research task

1. **Understand the actual question.** If the job description is genuinely ambiguous about
   scope (e.g. no budget/timeframe/region when that clearly matters), don't guess — ask one
   short question instead (see CLAUDE.md's "Unclear" handling), same rule as any other job.
2. **Search and read.** Use web search and page-fetching tools. Prefer a handful of good,
   checkable sources over one. For anything time-sensitive (prices, news, availability), note
   the date you looked.
3. **Never invent a fact or a source.** If you can't confirm something, say "I couldn't verify
   this" rather than presenting a guess as fact. If sources disagree, say so.
4. **Write the summary in plain language** — a few short paragraphs or a short list, not a wall
   of text. Assume Maroof hasn't read the sources himself.
5. **Always include real links** to the sources used, so Maroof can check them himself.
6. **Hand off to the verifier** with the summary and the source list — the verifier's Accuracy
   score specifically checks that sources are real and actually say what's claimed.
