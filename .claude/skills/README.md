# Skills index

Each folder here is one recipe: `.claude/skills/<name>/SKILL.md`. Check this list first before
improvising a plan for a job — if one fits, follow it exactly.

- `research-task` — for research/summary jobs.
- `file-task` — for file read/write/tidy jobs.
- `code-task` — for write-and-test-code jobs.
- `pending-reminder` — for the daily pending-jobs reminder to Maroof's personal email (drafts
  only).
- `daily-wrapup` — for a "daily wrap-up"/"end of day summary" job: a dated Done/Doing/Next
  summary saved to `log/YYYY-MM-DD.md`.

Add a new skill by creating a new folder with a `SKILL.md` inside (name, when to use it, steps,
example), then add one line to this list.
